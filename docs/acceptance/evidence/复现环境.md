# 本地复现环境

在仓库根目录、提交 `996b6b2`、Node 24 和 pnpm 10.22.0 下操作。下面的样稿和扩容文章均落在临时目录。

## 样稿与图片延迟

1. 运行 `node docs/m4.2/preview.mjs`。记录终端打印的本机地址及构建日志中以 `/dist/` 结尾的目录，保持预览进程运行。常规复现直接打开该地址下的 `/posts/lab-tech/` 或 `/posts/lab-depth/`。
2. 对 M4-01，另开终端，把下面命令的第一个参数换成刚记录的 **样稿 dist 绝对路径**。它只读取该目录，监听回环地址，为每张 WebP 增加 2 秒响应等待。
3. 浏览器禁用缓存，以 390 × 844 或 1440 × 900 打开 `http://127.0.0.1:39453/posts/lab-life/`，从导航前开始记录 Performance。保持页面静止，直至两张照片解码。结束后用 Ctrl+C 停止这两个本地进程。

```sh
python3 - "/样稿/dist" <<'PY'
from functools import partial
from http.server import SimpleHTTPRequestHandler, ThreadingHTTPServer
from sys import argv
from time import sleep

class MediaDelay(SimpleHTTPRequestHandler):
    def do_GET(self):
        if self.path.split("?")[0].endswith(".webp"):
            sleep(2)
        super().do_GET()

handler = partial(MediaDelay, directory=argv[1])
ThreadingHTTPServer(("127.0.0.1", 39453), handler).serve_forever()
PY
```

## 34 篇文章的归档和宽表

从仓库根目录执行。保留两篇正式文章，加 32 篇仅在临时目录中的已发布记录。构造方式复用现有测试夹具。此测试使用长值保留宽表的横向滚动空间。打开打印地址下的 `/posts/archive-00/`，结束后按 Ctrl+C。

```sh
node --input-type=module <<'JS'
import { execFileSync } from 'node:child_process';
import { mkdtemp, rm } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join, resolve } from 'node:path';
import { preview } from 'astro';
import { article, copySiteFixture } from './tests/fixtures.mjs';

const root = await mkdtemp(join(tmpdir(), 'm4-rail-'));
try {
  await copySiteFixture(root);
  const body = '## 表格\n\n| 列 | 值 |\n|---|---|\n| 项 | ' +
    '0123456789abcdef'.repeat(12) + ' |\n\n## 下文\n\n' +
    '用于滚动检验的正文。\n\n'.repeat(60);
  for (let n = 0; n < 32; n++) {
    const id = 'archive-' + String(n).padStart(2, '0');
    await article(join(root, 'src/content/posts'), id, { publishedAt: '2025-01-01' }, body);
  }
  execFileSync(process.execPath, [resolve('node_modules/astro/astro.js'), 'build', '--force'], {
    cwd: root, stdio: 'inherit',
  });
  const server = await preview({ root, server: { host: '127.0.0.1', port: 39452 } });
  await new Promise(done => { process.once('SIGINT', done); process.once('SIGTERM', done); });
  await server.stop();
} finally {
  await rm(root, { recursive: true, force: true });
}
JS
```
