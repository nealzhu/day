# M5.5 性能与网络

## 可比基线

使用 M4 之后、M5.1 之前的 `38e9a07` 对比本次候选的完整生产构建。两份静态产物使用同一个本地 gzip 服务参数，HTML 中仅将媒体和字体 CDN 前缀改到本地。媒体原件、字体版本和公开文章一致。Ego Lite Chromium 156 禁缓存，浅色、DPR 1。每个路由和视口采一次。HTML 体积含内联脚本和样式，外链资源以 HTTP 响应体字节计，CSS 合计包含 `faces.css`。 [逐请求记录](evidence/network.json)

| --- | ---: | ---: | ---: | ---: | ---: |
| 首页 | 4,335 → 7,009 B | 0 → 0 | 2／75,191 → 2／75,957 B | 18／538,300 → 18／538,300 B | 18／538,300 → 18／538,300 B |
| 有图详情 | 5,107 → 9,705 B | 0 → 2／3,069 B | 3／77,414 → 3／79,376 B | 19／578,808 → 19／578,808 B | 19／578,808 → 19／587,416 B |

12 次同条件冷读的 CLS 均为 0，60 组样稿矩阵最大 CLS 为 0.009969（1024 × 768 浅色随笔，向上取整）。首屏开销集中在交互入口与 HTML，页面没有提前下载 Pagefind 引擎、PhotoSwipe Core、灯箱 CSS 或 Giscus。移动无图详情的一个额外字体分包和有图详情的分包变化已记入问题清单。单次本机 `load` 值用于复查环境，无法推断真实用户加载分位数。 [页面矩阵](evidence/matrix.json) · [问题清单](ISSUES.md)

## 正式域名冷读

Ego Lite 在 1440 × 900 浅色、禁缓存下只读正式现网。此处字节使用 CDP `loadingFinished.encodedDataLength`，包含响应开销。JavaScript 计入正式环境的 Cloudflare 浏览器分析脚本，另有 `cdn-cgi/rum` 204 上报。三次首屏的 CLS 均为 0，未采到 Console 错误、HTTP 4xx/5xx 或请求失败。候选静态产物与现网分开记录。 [正式域名逐请求](evidence/network.json)
