# M6 性能预算

这些是面向 M6.2–M6.5 的建议实验室预算。分别按线上与本地、视口和节流档比较。测量方法和原始读数见 [M6.1 基线](BASELINE.md)。

## 首屏

| 指标 | M6.1 参考 | 建议预算 |
| --- | --- | --- |
| 正式移动限速 LCP | 卡片首页中位 1.332 s，分类 1.376 s，有图短文 0.948 s。首页有一次 16.476 s 连接前长等待 | 5 次中位 ≤1.5 s；常规传播档对任何 >2.5 s 的独立样本复查网络瀑布。保留真实样本极值。 |
| 正式移动限速 FCP | 首页 0.836 s，标题列表 0.888 s，有图短文 0.948 s | 中位 ≤1.1 s；渲染关键链新增 CSS 或同步脚本需与同组基线对比。 |
| 正式移动限速 HTML TTFB | 首页中位 331 ms，刷新 151 ms | 中位 ≤500 ms。真实地理网络独立做预算。连接等待及服务端时长分项保存。 |
| CLS | 常规 Chrome 的 520 次最大值 0.0226 | 常规实验上限 0.05；开启字体延迟和慢图实验时也比较变化源，目标 ≤0.05。 |
| Lighthouse 加载 TBT | 见 [独立 Lighthouse 基线](BASELINE.md#lighthouse-页面负载) | 生产移动限速中位 ≤100 ms，同组相对增长超过 50 ms 需查明新增长任务。 |
| 初始请求 | 正式移动卡片首页中位 26；其中字体 18 个 | 首页在可读内容与字体覆盖达标时 ≤28，省出的请求优先作为收益；首屏 Pagefind／PhotoSwipe Core／Giscus 均为 0。 |
| 生产冷读与刷新传输 | 移动限速首页 652,995 B／7,898 B | M6.2 之后首页冷读提案 ≤500 KiB；刷新 ≤25 KiB，已有 WOFF2 常规刷新传输为 0。 |
| WOFF2 冷读目标 | 正式首页约 533 KiB；本地长技术文、生活文约 865／840 KiB，长随笔约 1,337 KiB | M6.2 先验证短页 ≤375 KiB、长技术／图文 ≤650 KiB、独立随笔 ≤950 KiB，同时实际字形、字体交换与复用通过。 |
| HTML／JS 单页 | 首页 gzip 响应体约 6.9 KB；有图短文 9.6 KB。站点已发布的轻量脚本约 0.9／2.2 KB gzip | 先设首页 ≤12 KiB、技术长文 HTML 单独与原样稿比。第一方首屏外链 JS ≤8 KiB；线上第三方开销单报。 |

## 按需功能与静态交付

| 预算项 | 建议线 |
| --- | --- |
| Event Timing 与就绪 | 点击或键入的浏览器可见事件队列及处理按组比较，目标单次显示延迟 ≤100 ms。语义就绪另计。搜索弹窗目标 ≤100 ms，首次词条命中暂设原生中位 ≤1.2 s、移动限速 ≤2.5 s，再为 M6.4 设提升目标。 |
| 搜索初开、查询 | 初开 Pagefind 有效载荷 ≤110 KiB（CDP 与 Worker 补记口径固定）；两篇正式语料的首次关键词结果增量 ≤5 KiB，内容扩充时以同一版本语料比。重新打开首轮已载入索引，不产生额外初始化请求。 |
| 灯箱 | Core 与灯箱 CSS 首次增量 ≤25 KiB（不含图片）。已解码单图重新打开增量 0。线上样本首开目标 ≤400 ms 原生、≤900 ms 移动限速。 |
| 评论 | 整体性能增量只在接近评论区或点击后出现。访客原生就绪中位先设 ≤4 s，限速 ≤6 s；失败时仍可读正文，重复进入复用原 iframe。CORS 修复后访客选定字体对象成功率目标 100%。 |
| 生产构建 | 当前 28 文件、约 398 KiB。固定两篇校验语料下生产 `dist` ≤460 KiB，Pagefind ≤175 KiB。新文章增长时分开报告内容、索引和公共资源，继续排除隔离样稿及 CDN 媒体和字体副本。 |
| R2 与发布 | 无内容变动步骤保持 0 次条件 PUT、4 GET 字体冒烟；新增资源只写缺失对象。正常步骤暂设中位 ≤5 s，Pages 部署中位 ≤15 s。全量校验单列，保持完整性依赖。 |

预算变更前后使用相同路由、构建模式、网络、视口、Chrome 版本和清单版本，关键场景保留至少 5 个原始样本。中位数回退超过 15% 且超过 100 ms 的首屏或语义就绪结果做专门回查。不要合并多项假设后再猜测贡献。获取到真实流量时，另外对移动／桌面 P75 观察 LCP ≤2.5 s、INP ≤200 ms、CLS ≤0.1。真实用户预算与上述实验门槛独立。 [Web Vitals 口径](https://web.dev/articles/vitals)
