午后手记
========

窗纸上的光
----------

把两句写在相邻的源码行里，
它们仍属同一个段落。下面这两句各占一行，是当时抄下来的短诗。

杯中留半日，\
窗外过轻云。

### 字词的轻重

纸边用 *铅笔* 写的字略轻，**复校** 两字要重一点。交给排字员的那一句是 ***务必保留原行***。原本写作 ~~晴~~，抬头再看，改为薄阴。

普通文本里的 \* 只是星号。把 `&amp;` 写在反引号外就成了 &amp;，数字引用 &#x2615; 会排成杯子。要原样记下带反引号的写法，就用两个反引号包住它，例如 `` `茶` ``。

#### 引一段原话

> 开窗后，把杯子往里挪一点。
>
> > 杯沿太亮，容易看漏纸上的淡字。
>
> 后一句是傍晚补写的。
